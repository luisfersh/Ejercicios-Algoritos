## Uso del objeto `Math` en JavaScript

En esta práctica se utilizó la clase 
**`Math`** para realizar tareas y cálculos matemáticos avanzados de forma directa.

### Métodos y propiedades utilizados

* **Calcula el perimetro de un circulo `Math.PI`:**
  * **Uso:** Calcular el perímetro de un círculo.
  * **Para qué sirve:** Representa la relación entre la longitud de una circunferencia y su diámetro (aproximadamente 3.14159). Permite obtener la precisión exacta del número $\pi$ sin escribir decimales manuales.
  
* **Elevar un númeo a una potencia `Math.pow`:**
  * **Uso:** Elevar un número a una potencia.
  * **Para qué sirve:** Recibe dos datos numericos (la base y el exponente) y devuelve el resultado de elevar la base a dicha potencia.
  
* **Calcula la Raíz cuadrada de un número `Math.sqrt`:**
  * **Uso:** Calcular la raíz cuadrada de un número.
  * **Para qué sirve:** Retorna la raíz cuadrada exacta del valor ingresado.
